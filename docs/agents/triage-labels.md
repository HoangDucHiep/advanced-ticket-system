# Triage labels — ánh xạ cho skill dùng chung

Skill dùng chung nói bằng năm vai trò triage. Trong repo này chúng là giá trị của dòng `Status:`:

| Vai trò của skill | Giá trị dùng ở đây |
|---|---|
| `needs-triage`, `needs-info` | không dùng — ticket do AI lập theo plan |
| `ready-for-agent`, `ready-for-human` | `ready` (ai làm gì vẫn theo `Mode:`) |
| `wontfix` | xoá ticket, ghi lý do ở PR |

Trạng thái khác: `in-progress`, `in-review`, `done` — xem [`issue-tracker.md`](issue-tracker.md).
